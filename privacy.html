このアプリについて

「サーモンラン バイト記録」は、配信者が自分のYouTube配信でスプラトゥーン3のサーモンランのリザルト画面を読み取り、 記録の集計をこのサイトに載せ、記録を更新したときに自分の配信のライブチャットへコメントするための、個人用のツールです。

Googleアカウント（YouTube）で使う情報

  • YouTube Data API を使い、配信者が許可したアカウントとして、配信者自身のライブ配信のチャットにコメントを投稿します。
  • そのために、配信の情報（ライブチャットの場所）を読み取ります。
  • ログインの情報（アクセストークン）は配信者のPCの中だけに保存し、ほかの場所には送りません。
  • チャットの内容、視聴者の情報、そのほかのGoogleアカウントの情報は読み取りも保存もしません。

このサイトに載せる情報

  • リザルト画面から読み取ったゲームの記録（日時、WAVEごとの金イクラとノルマ、合計、赤イクラ、クリア／失敗）と、 シフトの情報（期間・ステージ・ブキ）だけを載せます。
  • 配信のURL・タイトル、視聴者の情報などの個人情報は載せません。
  • このサイトはアクセス解析やCookieを使っていません。

許可の取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、 いつでもこのアプリへの許可を取り消せます。
